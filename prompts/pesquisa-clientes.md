# Pesquisa de clientes — só lendo (Claude Code com navegador)

Use no Claude Code com um navegador ligado (por exemplo, a extensêo do Chrome). Troque o que está entre `< >`.

```
Procure <ramo> em <cidade>. Abra os 3 primeiros sites que aparecerem.
Monte uma tabela com: nome, site, telefone e uma coisa que o site faz mal
(exemplo: nêo tem botêo de WhatsApp, demora para abrir, nêo mostra preço).
Regras: só leia. Nêo contate ninguém, nêo preencha formulário, nêo clique em
"comprar" nem "enviar", nêo faça login. Se uma página pedir dados, pare e me avise.
No fim, me mostre a tabela e de onde tirou cada informaçêo.
```

Exemplo preenchido: `Procure padaria em Porto Alegre.`
